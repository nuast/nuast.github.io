<p>The NUAST Curriculum Hub is a public landing page for curriculum repositories used by students, staff, and parents. It provides a single, accessible entry point to Key Stage 3, Key Stage 4, and Key Stage 5 resources hosted in the NUAST GitHub organisation.</p>

<p>As a STEM-specialist school, NUAST promotes technical confidence, digital creativity, and strong academic foundations. This hub is designed to help users find the right curriculum area quickly and navigate to repository materials with minimal friction.</p>

<p>If you spot a broken link or need a repository added, please contact NUAST staff so the data source can be updated.</p>
